# Tech tools - build and test
Once we move from Java to TypeScript, we'll be using writing TypeScript, transpiling it to JavaScript and runniung it in webpages.

Also we'll be writing software tests.

While you may have used Node/npm/npx in past modules, `deno` is a tool (written by the same developer who wrote Node) made to make working with TypeScript projects quick and easy for common tasks. So that's what we'll be exploring ...

For those that have used TypeScript before, you'll find there is no **tsc** step, no package mangager, and much less config :-)
- also testing, type checking, formatting (pretty printing TS / HTML / CSS) is all built-in
