# Tech tools - build and test
Once we move from Java to TypeScript, we'll be using writing TypeScript, transpiling it to JavaScript and runniung it in webpages.

Also we'll be writing software tests.

While you may have used Node/npm/npx in past modules, `deno` is a tool (written by the same developer who wrote Node) made to make working with TypeScript projects quick, easy, and less config. So that's what we'll be exploring ...
